# Terkerder v1

City-state economy simulation for a phone. This checkpoint is version 1, saved before the automation rewrite.

The tagged release `v1.0.0` is the game as it plays now: nine industries, utilities, loans, saves, and charts. Later commits can change the model. This tag should stay put.

Play it at [ariedelhn.github.io/terkerder](https://ariedelhn.github.io/terkerder/). Saves stay in that browser.

To rebuild the GitHub Pages site: `npm run build:pages`.
